# Social post

- One post, one idea. 80-220 words. Land it.
- First line is a hook that works with no context (it shows in the feed alone).
  Not a summary, not "Excited to announce".
- Short paragraphs and line breaks. Plain language, no jargon walls.
- 0-3 hashtags, only if they genuinely widen reach. An optional one-line CTA at
  the end.
- Good hook: "Our cold starts were the reason customers churned. Not anymore."
  Weak hook: "Today we are announcing an update to our edge functions."
- Pull only from the scratchpad: its `body`, `sources`, and the chosen `angle`
  if there is one. Never invent a number, spec, price, date, quote, or result.
  Anything the scratchpad marks `[assumption]` or as an open question stays
  hedged.
- Return only the post text.
